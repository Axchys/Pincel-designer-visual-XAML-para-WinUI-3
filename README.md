# Pincel-designer-visual-XAML-para-WinUI-3
Designer de XAML para WinUI 3 (Windows 10/11) com a interface do Blend for Visual Studio. Abre soluções e projetos WinUI 3, permite desenhar telas arrastando controles e editar o XAML num editor Monaco com IntelliSense, sincronizados nos dois sentidos. Inclui gravação de estados visuais, linha do tempo de animações, trilhos de Grid, painel Git.
